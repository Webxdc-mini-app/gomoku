# 五目並べ for Delta Chat

Delta Chat のチャット内で遊べる webxdc 形式の五目並べアプリです。リバーシアプリの画面構成と対戦の流れを参考に作成しました。

- バージョン：1.0.0
- 表示言語：日本語
- CPU対戦：先手・後手を選択可能
- オンライン対戦：チャット相手との募集・参加・観戦・投了・色を交代した再戦

## 配布ファイル

| ファイル | 内容 |
| --- | --- |
| [gomoku-1.0.0.xdc](gomoku-1.0.0.xdc) | Delta Chat に送信して使用するアプリ |

## Delta Chat での始め方

1. 対戦相手との個別チャット、またはグループチャットを開きます。
2. `gomoku-1.0.0.xdc` をファイルとして添付して送信します。解凍は不要です。
3. チャットに表示されたアプリの投稿を開き、起動します。起動ボタンの名前や位置は端末によって異なります。
4. ひとりで練習する場合はCPU戦、チャット相手と遊ぶ場合はオンライン対戦を選びます。

**オンライン対戦では、双方が同じチャットの同じアプリの投稿を開いてください。** ファイルを別の投稿として送り直すと、別の対戦になります。

## 遊び方

### CPU対戦

- 「プレイヤー（黒）vs CPU（白）」は、あなたが先手です。
- 「CPU（黒）vs プレイヤー（白）」は、CPUが先手です。
- 自分の番になったら、空いている交点をタップまたはクリックします。
- 終局後は「最初からやり直す」で再び遊べます。

CPU戦は端末内で動作し、その操作はチャット相手に送信しません。CPUは勝てる手や相手の勝ちを防ぐ手を優先する簡易方式です。難易度の選択機能はありません。

### オンライン対戦

1. 双方が「チャット相手と対戦（オンライン）」を選びます。
2. 一方が「黒で募集」または「白で募集」を押します。
3. 相手は募集画面の「参加する」を押します。
4. 黒から交互に石を置きます。相手の番は更新が届くまで待ちます。

- 募集を取り消す場合は「募集をやめる」を押します。
- 同時に募集した場合は自動で対戦が始まることがあります。画面に表示された自分の色を確認してください。
- グループの他のメンバーは観戦できます。1つの対戦で石を置けるのは参加した2人です。
- 「投了」を押し、3秒以内に「本当に投了する？」をもう一度押すと投了が確定します。
- 終局後の「もう一度（色を交代）」は、同じ相手と色を交代して再戦します。相手の承諾を待つ確認画面はありません。
- 「メニューに戻る」だけではオンライン対戦は終了しません。再びオンラインを選ぶと続きの画面を開けます。

## ルールと画面の見方

- 盤面は15路盤です。黒が先手で、1手に1個ずつ空いている交点へ置きます。
- 縦・横・斜めに、自分の石を切れ目なく5個以上並べると勝ちです。
- 禁じ手はありません。長連（6個以上）、三三、四四も可能です。
- 盤面が埋まり、どちらも5個以上並んでいなければ引き分けです。
- 名前の横の数字は置いた石の数です。数字の大小で勝敗は決まりません。
- 最後に置いた石はオレンジ色の輪、勝った並びは緑色の輪で示します。
- 石を動かす機能や、着手を取り消す「待った」はありません。

## 保存と通信

オンライン対戦は、webxdc の更新履歴から状態を復元します。再び開いた直後は、履歴の読み込みと新着更新の受信を待ってください。CPU戦の途中経過は保存されず、CPU戦を選び直すと最初から始まります。

募集や着手は、相手に届くまで時間がかかる場合があります。画面下の受信件数と最後の受信時刻は更新の目安です。自分が送った更新を含むことがあり、相手の既読を示すものではありません。

## 困ったとき

| 状況 | 確認すること |
| --- | --- |
| 石を置けない | 自分の番か、交点が空いているか、すでに終局していないかを確認します。 |
| 相手の募集が見えない | 同じチャットの同じアプリ投稿を開いているか確認します。 |
| 相手の手が届かない | 少し待ち、両方の端末でDelta Chatの送受信ができるか確認します。 |
| 観戦中になる | 別の2人が対戦中です。終局後に新しく募集してください。 |
| テスト表示になる | 通常のブラウザで開いています。端末間で対戦する場合はDelta Chat内の `.xdc` の投稿から開き直します。 |
| 間違って置いた | 待った機能はありません。そのまま続けるか、相手と相談して投了・再戦してください。 |

## ソースの構成

```text
gomoku-1.0.0/
├── index.html       画面、スタイル、ゲーム処理、CPU、通信処理
├── manifest.toml    アプリ名とバージョンなどの情報
└── icon.png         アプリのアイコン
```

`.xdc` は上記3ファイルをルートに収めたZIP形式のファイルです。`webxdc.js` は実行環境から提供されるため、配布アプリには含めていません。

### 通常ブラウザでの確認

展開済みの `index.html` をブラウザで開くと、テスト用の動作になります。CPU戦を確認できます。ブラウザの同一オリジンにある別タブとは、対応環境で `BroadcastChannel` を使った模擬通信ができます。`file://` で開いた場合のタブ間通信はブラウザに依存します。他の端末との対戦確認にはDelta Chatを使用してください。

### 再パッケージ

ソースを変更した場合は、3ファイルがZIPの直下に入るように圧縮し、拡張子を `.xdc` にします。フォルダごと格納しないでください。配布版を更新する場合は、`manifest.toml` と `index.html` 内のバージョン表記も合わせて更新します。

## 確認した内容と制限

- 縦・横・両斜めの勝利判定、引き分け、不正な着手の拒否をロジックテストしました。
- CPUの勝ち手と、相手の即勝ちを防ぐ手を確認しました。
- オンライン処理の手番、投了、再戦をロジックテストしました。
- ブラウザでメニュー・対局・募集待ち・参加・終局画面を表示し、マニュアル用画面を作成しました。
- HTMLマニュアルのスマートフォン幅での表示と、PDFの全6ページを確認しました。
- **Delta Chatでの実機間通信は未確認です。**
- **Wordマニュアルの最終的な改ページは、この作成環境では確認できていません。** 印刷・配布前にWord等で確認してください。
